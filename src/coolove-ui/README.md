# coolove-ui（随仓库内置的副本）

这里的文件从 `D:\Code\coolove-ui` 同步而来，**不要直接改**：

- 需要调整基础组件时，先改 coolove-ui 仓库（并更新它的 CHANGELOG），再运行 `npm run sync:ui` 同步过来。
- 内置副本是为了让 CI 和其他机器不依赖本地的 coolove-ui 目录也能构建。

| --- | --- |
| `coolove-ui.css` | `coolove-ui/coolove-ui.css` |
| `useCooloveTheme.ts` | `coolove-ui/vue/useCooloveTheme.ts` |
